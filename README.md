# 🌷 Moodscape — Your Little Corner of Calm

> *Every mood has a place. Every feeling deserves to be heard.*

Moodscape is a mood-tracking and self-reflection web application designed to help people understand their emotions, express their thoughts, and discover small activities that support their everyday well-being.

Whether you're having a wonderful day, feeling overwhelmed, or simply need a moment to yourself, Moodscape gives you a little space to pause, reflect, and reconnect with yourself.

---

## ✨ Features

### 😊 Mood Check-in
- Choose from six different emotional states.
- Track the intensity of your current mood.
- Record your daily emotional experiences.

### 📖 Personal Journal
- Write down your thoughts and feelings.
- Keep track of personal reflections.
- Save journal entries alongside your mood records.

### 🌱 Mood-Based Recommendations
- Discover activities based on your selected mood.
- Get suggestions for relaxation, creativity, and self-care.
- Explore simple ways to make your day better.

### 💌 Daily Affirmations
- Receive positive and encouraging messages.
- Find reminders that encourage self-kindness and self-reflection.

### 📊 Mood History
- View previously saved mood entries.
- Track your mood check-ins.
- Review your recorded emotional experiences.

### 💾 Local Data Storage
- Uses browser LocalStorage to save mood entries.
- Retains saved entries after refreshing the page.
- No backend or database setup required.

## 🎨 Design Philosophy

Moodscape is designed around a calm, minimal, and dreamy visual experience.

- Soft pastel gradients.
- Lavender and pink colour palette.
- Rounded cards and interactive elements.
- Responsive layouts for desktop and mobile.
- Simple navigation and beginner-friendly interactions.

The goal is to create an environment where users feel comfortable expressing themselves.

## 🚀 Getting Started

Follow these steps to run Moodscape locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Moodscape
```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.

That's it! Moodscape is ready to explore.

## 🎯 Project Objective

The primary objective of Moodscape is to encourage emotional awareness and daily self-reflection through a simple, accessible, and interactive digital experience.

It aims to remind users that every emotion is valid and that taking care of yourself starts with understanding yourself.
